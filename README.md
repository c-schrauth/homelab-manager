- Infrastructure inventory
- Docker discovery
- Proxmox integration
- Service health monitoring
- Security and exposure monitoring
- Backup monitoring
- Web dashboard
- REST API
- Automated testing
- CI/CD
- Containerized deployment

- PostgreSQL
- Docker
- GitHub Actions
